# StudyFlow

Учебный проект по программной инженерии на GitHub. Каталог материалов служит общим примером для документации, гибкого планирования, Kanban, календаря поставок и CI/CD.

## Запуск

Требуется Python 3.10 или новее. Внешних Python-пакетов нет.

```text
python -m unittest -v
python build.py
python -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Поиск и выбор темы фильтруют каталог, кнопка материала сохраняет его в истории браузера. Кнопка недавно просмотренных показывает изученные материалы.
